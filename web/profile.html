what happens to a handle you enter
  • No one else can see it. There is no public profile, no leaderboard, and no page or endpoint that takes a username and shows you someone's account. Every query the server makes for your data is scoped to your own session.
  • It's encrypted in the database. Handles and the stats fetched with them are stored as AES-256-GCM ciphertext. The key lives in the application's environment, not in the database, so a copy of the database — a backup, a leaked connection string, a breach at the database host — is unreadable on its own.
  • The judges see it, unavoidably. To show your solved counts and heatmap, the server asks LeetCode, Codeforces, CodeChef, GitHub or AtCoder about that username. Those requests go to them directly. Nothing can change that and it would be dishonest to imply otherwise.
  • Deleting is immediate. Clear a field and save: the handle row and its cached stats are deleted, not flagged.
  • What I can't promise. I run the server, and any operator can in principle read what their own server processes — so "even the admin can't see it" would be a lie, and you should distrust any site that claims it. What's true is that it isn't stored readably, it's one click from deletion, and the code is public if you'd rather check than take my word.
